# TransitPulse

TransitPulse is a transport reliability analytics platform that helps commuters understand how dependable public transport routes are using historical and real-time transport data.

## Goals

- Analyze transport reliability
- Calculate route reliability scores
- Visualize delay trends
- Provide actionable commuter insights

## Tech Stack

- C#
- .NET 9
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
- Clean Architecture
- Repository Pattern
- Dependency Injection
- REST API
- xUnit
- Moq
- Git & GitHub

## Development

This project follows GitHub Actions CI and automated testing.
